## 1. Unity verification (the hard gate)

- [ ] Import the package into a **clean Unity 2022.3 LTS**
  project (the version in `package.json`: `"unity": "2022.3"`,
  `"unityRelease": "0f1"`). Confirm **zero errors and zero
  warnings** in the Console. A single warning is a fail — fix
  it or justify it in writing before proceeding.
- [ ] Run the full 7-step test checklist in `README.md`
  (demo-item creation, demo scene Play-mode run with keys 1–6,
  `InventorySelfTest` ending `DONE: 0 failed`, custom
  inspector check, save/load round-trip, standalone player
  build with no errors). Every step must pass.
- [ ] Confirm the demo scene plays end-to-end with no Console
  errors, including after a fresh re-import.
- [ ] Only after all of the above passes, update the version
  note: remove "UNTESTED IN UNITY" from `README.md`,
  `CHANGELOG.md`, `Documentation~/GUIDE.md`, `LISTING.md`, and
  the editor window label — and record what was actually run
  (Unity version, platform, date). Do not remove the note on
  the strength of a partial run.

## 2. Documentation

- [ ] `README.md` proofread — no typos, no wrong method names,
  no claims the code does not support.
- [ ] `Documentation~/GUIDE.md` proofread — API reference
  checked against the actual `Runtime/*.cs` files (every
  class/method listed must exist with that exact name).
- [ ] `LISTING.md` proofread — short description re-counted
  (must stay under 200 characters), price and comparables
  re-checked (see §5), no sales/reviews claimed.
- [ ] `CHANGELOG.md` accurate for v0.1.0.
- [ ] `ThirdPartyNotices.txt` still accurate (no third-party
  material added since it was written).

## 3. Screenshots, video, and icon (real captures only)

- [ ] **At least 5 screenshots**, all **real Unity screenshots**
  of the actual demo scene / editor in Unity 2022.3 LTS —
  inspector views, demo scene in Play mode, Console output.
- [ ] Screenshots at **1920x1080**.
- [ ] **No AI images presented as screenshots.** Concept art
  (including any images made for the Roblox/Unity brand work)
  must never appear in the listing as if it were the product.
  If concept art is used anywhere in the listing at all, it
  must be labelled as concept art.
- [ ] **AI-content disclosure:** if any image in the listing
  (including the icon or a key image) was made with AI tools,
  disclose that in the listing as the Asset Store requires.
  When in doubt, disclose.
- [ ] **30–60 second video**, a **real Unity recording only**
  (screen capture of the demo scene being played: keys 1–6,
  equip/use/drop, Console output). No AI-generated video, no
  stock footage standing in for the product.
- [ ] **Icon 512x512** for the store listing. Must be original
  art for this package (not copied from another asset, not an
  AI image passed off as a screenshot — see the disclosure rule
  above).

## 5. Price and comparables — re-check before listing

- [ ] Re-check the comparables named in `LISTING.md` (Vault
  Inventory $39.99, Universal Inventory System $14, older
  Inventory System $4.99) — prices change, assets get
  delisted, and new competitors appear. Update the listing if
  any comparable has moved.
- [ ] Confirm the suggested **$25** price still sits in the
  **$15–$35** range for a new publisher chasing first reviews.
  Do not raise it to $95 on day one.
- [ ] Understand the maths, not the promise: 70% net on $25 is
  **$17.50 per sale before tax/refunds/fees**. The price
  guarantees no sales. No sales figure may appear in the
  listing.

## 6. Submission rules and timing

- [ ] **Review takes at least 5 business days.** Plan for it;
  do not promise buyers a date, and do not submit the day
  before you need the listing live.
- [ ] **5 submissions/month cap in the first 6 months.**
  Submissions include new assets and updates — do not burn
  them on sloppy drafts. This package should be submitted
  once, correctly, not iterated through rejections.
- [ ] Read the current Asset Store submission guidelines once
  more at submission time (they change). In particular,
  re-check: the suggested category (Tools / Game Toolkits),
  the keyword list, the AI-content disclosure rules, and the
  screenshot/video specifications.
- [ ] Keep a copy of exactly what was submitted (package
  version, listing text, screenshots, video) so a rejection
  can be answered from the record, not from memory.
